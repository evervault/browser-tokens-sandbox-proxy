# Security policy

## Report a vulnerability

Email [security@evervault.com](mailto:security@evervault.com) with a description of the issue, the steps to reproduce it, the affected versions, and any mitigations you know of. Our PGP key is at [evervault.com/pgp.pub](https://evervault.com/pgp.pub).

This project follows a 90-day disclosure timeline. Evervault doesn't currently run a bug bounty program.
